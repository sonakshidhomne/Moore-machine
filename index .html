Moore Machine Model • Right-to-Left Processing

Result

Method: Starting from the rightmost bit, copy bits through the first 1; then complement all remaining bits.

The input is processed from right to left.

Moore Machine States

Copy 0 while scanning from right to left.
q1 — First 1
The first 1 from the right is copied.
q2 — Complement
All remaining bits are inverted.
